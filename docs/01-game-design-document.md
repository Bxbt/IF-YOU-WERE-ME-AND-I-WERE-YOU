## A1. Game Vision

> "I may never feel exactly what you feel, but I want to understand."

เกมเล็ก ๆ ที่คนสองคนใช้เป็นพื้นที่ปลอดภัยในการเข้าใจตัวเองและกันและกัน ผ่านเรื่องเล่าที่ทำให้ได้ "ยืนในรองเท้าของอีกฝ่าย" เป็นเวลาสั้น ๆ

**ผู้เล่นควรรู้สึกหลังเล่นจบ:**
- รู้จักความต้องการทางอารมณ์ของตัวเองชัดขึ้น
- เห็นว่าสิ่งที่ตัวเองคิดเกี่ยวกับคู่ เป็น "สมมติฐาน" ที่ควรถาม ไม่ใช่ข้อเท็จจริง
- มีคำถามอย่างน้อย 3 ข้อที่อยากชวนคู่คุยต่อ
- ไม่รู้สึกว่าถูกตัดสิน ถูกให้คะแนน หรือถูกบังคับให้ขอโทษ

**ข้อความหลักของเกม:**
1. Understanding doesn't mean agreeing.
2. Loving someone doesn't mean thinking alike.
3. Sometimes, we simply need to see the world through another person's eyes.

## A2. Core Concept

**หนึ่งเหตุการณ์ สองมุมมอง สามชั้นของความเข้าใจ**

| ชั้น | คำถามที่เกมถาม | ระบบ |
|---|---|---|
| 1. ฉันเป็นอย่างไร | "เวลาคุณกลัว คุณต้องการอะไร" | Self-reported profile |
| 2. ฉันคิดว่าเธอเป็นอย่างไร | "คุณคิดว่าเขาต้องการอะไร" | Perceived profile |
| 3. เราเห็นตรงกันไหม | เปิดคำตอบพร้อมกัน | Perspective Mirror + Comparison |

**Hook เรื่อง:** เย็นวันฝนตก คนหนึ่งลงไปรับพัสดุแล้วติดลิฟต์ 30 นาที อีกคนรออยู่ในห้องโดยไม่รู้ว่าเกิดอะไรขึ้น ทั้งคู่ห่างกันแค่ไม่กี่ชั้น แต่ประสบการณ์ต่างกันโดยสิ้นเชิง เมื่อเจอกันอีกครั้ง คำแรกที่พูดออกมาอาจไม่ใช่สิ่งที่อยู่ในใจจริง ๆ

**Signature Feature: "What You See vs. What I Feel"** — หลังฉากพบกัน ผู้เล่นแต่ละคนบอกว่าตัวเองรู้สึกอะไรจริง ๆ และเดาว่าอีกฝ่ายรู้สึกอะไร แล้วเปิดเทียบกัน (ดู [02](02-story-script.md) Ch3 และ [04](04-personality-system.md) §6)

## A3. Target Audience

| มิติ | รายละเอียด |
|---|---|
| หลัก | คู่รักอายุ 18+ ที่อยากเข้าใจกันมากขึ้น ไม่ว่าคบกันมานานแค่ไหน (A-18) |
| รอง | คนที่อยากสะท้อนตัวเองเรื่องความสัมพันธ์ แม้คู่ไม่ได้เล่นด้วย |
| ภาษา | ไทย |
| อุปกรณ์ | มือถือเป็นหลัก (Mobile-first), แท็บเล็ต, เดสก์ท็อป |
| ประสบการณ์เกม | ไม่จำเป็นต้องเล่นเกมเป็น ควบคุมด้วยการแตะ/คลิกเท่านั้น |
| ระยะเวลาเล่น | ทั้งเกมประมาณ 45–70 นาที แบ่งเล่นได้ทีละบท บทละ 8–15 นาที |

**ไม่ใช่กลุ่มเป้าหมาย / ไม่เหมาะกับ:** ความสัมพันธ์ที่มีความรุนแรงหรือการควบคุม — เกมจะแสดงข้อความแนะนำแหล่งช่วยเหลือในหน้า About และ Safety (ดู [08](08-privacy-and-safety.md) §9) และไม่ควรถูกใช้เพื่อบังคับให้อีกฝ่ายเปิดเผยความรู้สึก

**ความเป็นกลางด้านเพศ:** เกมไม่ระบุเพศของตัวละคร ใช้ชื่อแทนสรรพนาม ผู้เล่นเลือกคำลงท้ายได้ (A-04) รองรับคู่ทุกรูปแบบ

## A4. Game Mechanics

### A4.1 Core Loop (ต่อหนึ่งบท)

```
ฉากเปิด → เรื่องเล่า + Dialogue → ตัวเลือก → ผลทางอารมณ์ (บทพูด/บรรยากาศเปลี่ยน)
        → ตีความความรู้สึก (ยืนยัน/ปฏิเสธ) → คำถามสะท้อน (ส่วนตัว) → ฉากจบ → บทถัดไป
```

### A4.2 รายการ Mechanics

| Mechanic | คำอธิบาย | เงื่อนไขการทำงาน | Phase |
|---|---|---|---|
| Dialogue System | กล่องข้อความแบบพิมพ์ทีละตัว แตะเพื่อข้ามได้ | ทุกบท | MVP |
| Internal Monologue | ความคิดในใจ แสดงเป็นกล่องตัวเอียง สีจาง มีไอคอน "ความคิด" | ทุกบท | MVP |
| Choice | 2–4 ตัวเลือก ไม่มีตัวเลือกที่ถูก/ผิด ทุกตัวเลือกมีผลเชิงอารมณ์ (บทพูดตอบกลับ หรือบรรยากาศเปลี่ยน) | ทุกบท | MVP |
| Emotional Echo | ตัวเลือกก่อนหน้าส่งผลต่อบทพูดในฉากถัดไป (ผ่าน flag) ไม่มีคะแนน | Ch1–Ch3 | MVP |
| Environmental Change | ฝน แสง แบตเตอรี่โทรศัพท์ สัญญาณ เปลี่ยนตาม Timeline และตัวเลือก | Ch1–Ch2 | MVP |
| Perspective Switch | สลับไปเล่นอีกบทบาท มีแถบบอกชัดเจนว่ากำลังเล่นเป็นใคร | Ch2 | MVP |
| Imagined Banner | ใน Play Alone เมื่อเล่นเป็นคู่ จะมีแถบ "นี่คือสิ่งที่คุณจินตนาการว่า {ชื่อ} อาจรู้สึก" ตลอดฉาก | Ch2–Ch4 (Alone) | MVP |
| Interpretation Check | เกมเสนอ "ความรู้สึกที่อาจอยู่เบื้องหลัง" ผู้เล่นเลือก ใช่/ไม่ใช่/ไม่แน่ใจ เอง | Ch3 | MVP |
| Reflection Question | คำถามท้ายบท ตอบเป็นตัวเลือกหรือข้อความ เป็นส่วนตัวเสมอ | ทุกบท | MVP |
| Perspective Mirror | ตอบคำถามเดียวกันสองแบบ (ตัวเอง + เดาคู่) แล้วเปิดเทียบ | Ch3–Ch4 | MVP (คนเดียว) / P2 (สองคน) |
| Mutual Reveal | เปิดคำตอบเมื่อทั้งสองตอบครบและกดยินยอม | Mirror, Ch5 | P2 |
| Completion Statements | เติมประโยค 5 ข้อ เลือกแชร์ทีละข้อ | Ch5 | MVP |
| Personality Profile | แบบสอบถามฉบับสั้น/เต็ม แก้ไขได้ตลอด | นอกบท | MVP |
| Observed Pattern | สังเกตตัวเลือกซ้ำในเนื้อเรื่อง แสดงเป็น "อาจ" และลบได้ | Report | P2 (audit M-7) |
| Pause / Skip | หยุดได้ทุกเมื่อ ข้ามฉาก/คำถาม/ทั้งบทได้ | ทุกที่ | MVP |
| Memory Scenes | ผู้เล่นสร้างฉากจากเหตุการณ์ของตัวเอง | นอกบท | P2 (A-06) |

### A4.3 สิ่งที่ "ไม่มี" ในเกมโดยเจตนา

- ไม่มีคะแนน ตัวเลข เปอร์เซ็นต์ ดาว หรือ Progress bar ที่สื่อความ "เข้าใจกันมากน้อย"
- ไม่มี Game Over, ไม่มี Bad Ending, ไม่มีการลงโทษตัวเลือก
- ไม่มีการจับเวลาในการตอบ
- ไม่มีตัวเลือกที่ถูกทำเครื่องหมายว่า "ถูก" หรือ "ดีกว่า"
- ไม่มีการบังคับขอโทษ บังคับกอด หรือบังคับคืนดี — ทุกฉากที่มีการกอดหรือขอโทษมีตัวเลือกที่ไม่ทำด้วย

## A5. Game Modes

| | Play Alone | Play Together | Play Remotely |
|---|---|---|---|
| Phase | MVP | Phase 2 | Phase 3A / 3B |
| ผู้เล่นจริง | 1 | 2 บนเครื่องเดียว | 2 คนละเครื่อง |
| คู่ในเกม | Imagined Partner (ข้อมูลจากผู้เล่นเท่านั้น) | ผู้เล่นจริง | ผู้เล่นจริง |
| ความลับ | ทุกอย่างเป็นส่วนตัว | Handoff screen + PIN ทางเลือก | แยกเครื่อง + การควบคุมการเข้าถึง |
| Mirror | ตัวเอง vs สิ่งที่เดา (คำตอบจริงของคู่ = "ยังไม่รู้") | A vs B ทั้งสองทิศ | A vs B ทั้งสองทิศ |
| เนื้อเรื่อง Ch1–Ch3 | เล่นทุกบทบาท | เจ้าของบทบาทเลือก ดูด้วยกัน | เล่นทุกบทบาทบนเครื่องตัวเอง (ไม่รออีกฝ่าย) |
| Report | ส่วนตัว | ส่วนตัวต่อคน + Shared Reflection | ส่วนตัวต่อคน + Shared Reflection |
| ต้องใช้ Backend | ไม่ | ไม่ | 3A ไม่ / 3B ใช่ |

รายละเอียด Flow ดู [05-game-flow.md](05-game-flow.md)

### A5.1 กฎสำคัญของ Play Alone

- คู่ในเกมสร้างจากสิ่งที่ผู้เล่นป้อนเท่านั้น เกมไม่เติมบุคลิกให้คู่เอง
- ทุกหน้าจอที่แสดงข้อมูลของคู่ต้องมีป้าย **"สิ่งที่คุณคิด"** หรือ **"สิ่งที่คุณจินตนาการ"**
- ช่องคำตอบจริงของคู่แสดงสถานะ **"ยังไม่รู้ — ลองถาม {ชื่อ} ดู"** ไม่แสดงเป็นค่าว่างแบบเงียบ ๆ
- เล่นจบได้ครบโดยไม่ต้องมีผู้เล่นคนที่สอง
- ภายหลังสามารถ "ชวนคู่มาเล่น" ได้ (Phase 2/3) โดยสร้าง Journey ใหม่และเชื่อม Imagined Partner กับคู่จริง ([05](05-game-flow.md) §4.3) ข้อมูล Perceived ยังอยู่ และไม่ถูกแสดงให้คู่เห็นจนกว่าจะยินยอม

## A6. Player Journey

### A6.1 First-time Player (Play Alone)

| ขั้น | หน้าจอ | สิ่งที่ผู้เล่นทำ | เวลาโดยประมาณ |
|---|---|---|---|
| 1 | Title | กด "เริ่มการเดินทางใหม่" | — |
| 2 | Safety Intro | อ่านข้อตกลงสั้น ๆ: ไม่มีคะแนน ข้ามได้ หยุดได้ | 30 วิ |
| 3 | Mode Selection | เลือก "เล่นคนเดียว" | — |
| 4 | Character Creation | สร้างตัวเอง + สร้าง "คู่ในจินตนาการ" (ชื่อ, รูปลักษณ์) | 2–3 นาที |
| 5 | Personality Setup (ทางเลือก) | ฉบับสั้น 12 ข้อ หรือข้ามไปก่อน | 3–5 นาที |
| 6 | Chapter Select | เริ่ม Ch1 | — |
| 7 | Ch1–Ch5 | เล่นเนื้อเรื่อง | 40–60 นาที |
| 8 | Comparison | ดู 3 หมวด: เข้าใจคล้ายกัน / อาจต่างกัน / ควรถามกัน | 3 นาที |
| 9 | Report | ดู แก้ เลือกส่งออก | 3 นาที |
| 10 | Ending | ข้อความปิด → กลับ Title | — |

### A6.2 Returning Player

Title → "เล่นต่อ" → กลับไปที่ฉากล่าสุดที่บันทึก (Autosave ทุกตัวเลือก) หรือเลือกบทจาก Chapter Select

### A6.3 Emotional Arc

```
Ch1 อบอุ่น→ตึงเครียด   Ch2 กลัว/กังวล (จุดต่ำสุด)   Ch3 ปะทะ→เข้าใจ   Ch4 สำรวจ/อยากรู้   Ch5 สงบ/อบอุ่น
```

บรรยากาศภาพเปลี่ยนตาม Arc: แสงอุ่นในห้อง → ลิฟต์มืดแสงฉุกเฉิน + ฝนหนัก → ล็อบบี้แสงขาว → ห้องนั่งเล่นตอนกลางคืน → ดาดฟ้าใต้ดาว

## A7. Design Principles

| # | หลักการ | การนำไปใช้ที่ตรวจสอบได้ |
|---|---|---|
| P1 | **No Judgment** ไม่ตัดสิน | ไม่มีคะแนน/อันดับ ข้อความทุกข้อผ่าน Content Checklist ใน [02](02-story-script.md) §0.4 |
| P2 | **Assumption ≠ Fact** | ข้อมูล Perceived และ Imagined มีป้ายกำกับทุกครั้งที่แสดง |
| P3 | **Private by Default** | ไม่มีคำตอบใดถูกแสดงให้อีกฝ่ายจนกว่าจะยินยอม |
| P4 | **Always an Exit** | ทุกหน้าจอมีทางกลับ/หยุด/ข้าม ไม่มี Dead end |
| P5 | **Both Sides Are Valid** | ทุกฉากที่มีความขัดแย้งให้เวลาและพื้นที่บทพูดแก่ทั้งสองบทบาทเท่ากัน |
| P6 | **Accountability + Empathy** | เกมยอมรับว่าความกังวลมีเหตุผล แต่ไม่ยอมรับว่าความกังวลเป็นเหตุผลให้พูดทำร้าย |
| P7 | **Honest Technology** | ไม่กล่าวอ้างความปลอดภัยหรือการ Sync ที่ไม่ได้ทำจริง |
| P8 | **Cozy, Not Clinical** | ภาษาอบอุ่น ไม่ใช้ศัพท์จิตวิทยา ไม่มีหน้าตาแบบ Dashboard |
| P9 | **Readable First** | ข้อความทุกชิ้นเป็น HTML text ไม่ฝังในภาพ ผ่าน Contrast AA |
| P10 | **Consent for Touch** | การกอด/สัมผัสในเกมเป็นตัวเลือกเสมอ และมีตัวเลือก "ขอถามก่อน" |
