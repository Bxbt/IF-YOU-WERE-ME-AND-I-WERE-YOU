## 0. Conventions

| D01 | `emotional_expression` | การแสดงออกทางอารมณ์ | แสดงความรู้สึกออกมามากน้อยแค่ไหน อย่างไร |
| D02 | `communication` | รูปแบบการสื่อสาร | ชอบสื่อสารแบบไหน ช่องทางไหน จังหวะไหน |
| D03 | `conflict_response` | ปฏิกิริยาต่อความขัดแย้ง | สิ่งที่ทำโดยอัตโนมัติเมื่อเกิดความขัดแย้ง |

| D05 | `comfort_style` | รูปแบบการปลอบใจที่ต้องการ | อยากได้รับการปลอบแบบไหน |
| D06 | `problem_solving` | การแก้ปัญหา | ชอบแก้ปัญหาทันที หรืออยากถูกรับฟังก่อน |
| D07 | `personal_space` | พื้นที่ส่วนตัว | ต้องการเวลาและพื้นที่ของตัวเองแค่ไหน |
| D08 | `affection` | การแสดงความรัก | แสดงความรักออกมาอย่างไร |
| D09 | `stress_reaction` | ปฏิกิริยาต่อความเครียด | เมื่อเครียดมักทำอย่างไร |
| D10 | `conflict_resolution` | การคลี่คลายความขัดแย้ง | อยากให้ความขัดแย้งจบลงแบบไหน |
| D11 | `boundaries` | ขอบเขตส่วนตัว | สิ่งที่สำคัญต่อความรู้สึกปลอดภัยและการเคารพ |
| D12 | `feeling_valued` | การรู้สึกมีคุณค่า | อะไรทำให้รู้สึกว่าได้รับการเห็นคุณค่า |

### 0.2 Meta Options (ทุกคำถามมี)

| ID | ข้อความ | พฤติกรรม |
|---|---|---|
| `meta_depends` | ขึ้นอยู่กับสถานการณ์ | เลือกแทนตัวเลือกปกติ ใส่ข้อความอธิบายได้ (ไม่บังคับ) · ไม่เลือกร่วมกับตัวเลือกปกติ |
| `meta_not_sure` | ไม่แน่ใจ | บันทึกว่าไม่แน่ใจ ใส่ข้อความได้ |
| `meta_prefer_not` | ไม่สะดวกตอบ | บันทึก ไม่แสดงให้อีกฝ่ายเห็นเลยแม้ Reveal (แสดงว่า "ไม่ได้ตอบ") · ไม่ถามซ้ำจนกว่าผู้เล่นจะแก้เอง |
| `meta_skip` | ข้าม | ไม่บันทึกคำตอบ สถานะ `skipped` · กลับมาตอบได้ภายหลัง · เกมอาจถามอีกครั้งเมื่อเปิด Personality Setup |

### 0.3 รูปแบบคำถามสองชั้น

ทุกข้อมี 2 รูปแบบ:
- **Self:** ถามเกี่ยวกับตัวผู้เล่นเอง → `layer=self`
- **Perceived:** ถามว่าผู้เล่นคิดว่าคู่เป็นอย่างไร → `layer=perceived` (ใช้ Option ชุดเดียวกัน)

ข้อความ Perceived ใช้ token `{other}` ป้ายกำกับบนหน้าจอ: **"สิ่งที่คุณคิดเกี่ยวกับ {other}"**

### 0.4 ฟิลด์ของแต่ละคำถาม

| ฟิลด์ | คำอธิบาย |
|---|---|
| `id` | Q01–Q36 |
| `dimension` | D01–D12 |
| `self` / `perceived` | ข้อความคำถาม |
| `options` | id + ข้อความ (id ใช้ในการเปรียบเทียบ ห้ามเปลี่ยนหลังปล่อย) |
| `maxSelect` | จำนวนที่เลือกได้สูงสุด |
| `freeText` | อนุญาตข้อความอิสระ (ทุกข้อ = ใช่, สูงสุด 280 ตัวอักษร) |
| `interpretation` | แนวทางการตีความสำหรับระบบและผู้เขียน Content — **ไม่แสดงให้ผู้เล่นเห็นตรง ๆ** ใช้สร้างข้อความใน Report |
| `reflectionPrompt` | คำถามชวนคุย แสดงใน Report / Comparison หมวด "ควรถามกัน" |
| `quick` | อยู่ในฉบับสั้น 12 ข้อหรือไม่ (A-14) |

**หลักการตีความร่วมทุกข้อ:** ไม่มีตัวเลือกใดดีหรือแย่กว่ากัน คำตอบสะท้อน "ความชอบในตอนนี้" ไม่ใช่ลักษณะถาวร ห้ามแปลงเป็นป้ายบุคลิก (เช่น "คุณเป็นคนเก็บกด")

## 1. Personality Questions (Q01–Q36)

### D01 — การแสดงออกทางอารมณ์

#### Q01 ⭐quick
- **Self:** เวลามีเรื่องอะไรรบกวนใจ ปกติคุณทำอย่างไร
- **Perceived:** คุณคิดว่าเวลามีเรื่องรบกวนใจ {other} มักทำอย่างไร
- **maxSelect:** 2
- **Options:**
  - `q01_talk_now` พูดออกมาทันที
  - `q01_process_first` ขอเวลาคิดก่อน แล้วค่อยพูด
  - `q01_wait_asked` รอให้มีคนถาม
  - `q01_handle_private` จัดการเองเงียบ ๆ
  - `q01_show_not_say` ไม่พูด แต่คนรอบตัวมักดูออก
- **Interpretation:** บอก "จังหวะ" ของการเปิดเผยความรู้สึก ไม่ได้บอกว่ารู้สึกมากหรือน้อย ถ้า Self = `process_first` แต่ Perceived ของคู่ = `talk_now` → จุดที่ควรคุยเรื่องจังหวะ
- **Reflection Prompt:** "เวลามีเรื่องในใจ อยากให้อีกคนเข้ามาถามเลย หรือรอให้เราพร้อมก่อน?"

#### Q02
- **Self:** คุณแสดงความเศร้าออกมาให้คนใกล้ตัวเห็นได้ง่ายแค่ไหน
- **Perceived:** คุณคิดว่า {other} แสดงความเศร้าให้คุณเห็นได้ง่ายแค่ไหน
- **maxSelect:** 1
- **Options:**
  - `q02_easy` ง่าย แสดงออกตามที่รู้สึก
  - `q02_trusted_only` แสดงเฉพาะกับคนที่ไว้ใจมาก ๆ
  - `q02_after_time` แสดงได้ แต่ต้องใช้เวลา
  - `q02_rarely` ไม่ค่อยแสดงออก
- **Interpretation:** ความยากในการแสดงความเศร้าไม่เท่ากับการไม่ไว้ใจ อาจมาจากนิสัย ครอบครัว หรือความเกรงใจ
- **Reflection Prompt:** "มีอะไรที่อีกคนทำแล้วทำให้เรากล้าแสดงความเศร้าออกมามากขึ้นไหม?"

#### Q03
- **Self:** เวลาดีใจมาก ๆ คุณมักแสดงออกอย่างไร
- **Perceived:** คุณคิดว่าเวลา {other} ดีใจมาก ๆ มักแสดงออกอย่างไร
- **maxSelect:** 2
- **Options:**
  - `q03_share_now` รีบเล่าให้คนสำคัญฟัง
  - `q03_celebrate` อยากฉลองด้วยกัน
  - `q03_quiet_joy` ยิ้มอยู่ในใจ เก็บไว้เงียบ ๆ
  - `q03_physical` กอด กระโดด แสดงออกทางร่างกาย
  - `q03_post` เขียนหรือโพสต์เก็บไว้
- **Interpretation:** การแสดงความสุขต่างกันไม่ได้แปลว่าสุขไม่เท่ากัน คนที่ "ยิ้มในใจ" อาจรู้สึกถูกกดดันถ้าคู่คาดหวังการฉลอง
- **Reflection Prompt:** "ครั้งล่าสุดที่เราดีใจมาก ๆ อยากให้อีกคนร่วมดีใจด้วยวิธีไหน?"

### D02 — รูปแบบการสื่อสาร

#### Q04 ⭐quick
- **Self:** เรื่องสำคัญ ๆ คุณชอบคุยผ่านช่องทางไหนมากที่สุด
- **Perceived:** คุณคิดว่า {other} ชอบคุยเรื่องสำคัญผ่านช่องทางไหน
- **maxSelect:** 2
- **Options:**
  - `q04_face` คุยต่อหน้า
  - `q04_call` โทรคุย
  - `q04_text` พิมพ์ข้อความ (ได้เรียบเรียงก่อน)
  - `q04_walk` คุยระหว่างทำอย่างอื่นด้วยกัน เช่น เดินเล่น ขับรถ
  - `q04_letter` เขียนยาว ๆ เป็นจดหมายหรือโน้ต
- **Interpretation:** การเลือก `text` หรือ `letter` มักสัมพันธ์กับความต้องการเรียบเรียงความคิด ไม่ใช่การหลีกเลี่ยง
- **Reflection Prompt:** "ถ้ามีเรื่องยาก ๆ จะคุย อยากเริ่มคุยกันแบบไหน?"

#### Q05
- **Self:** เวลาคุยเรื่องสำคัญ อะไรทำให้คุณรู้สึกว่าอีกคนฟังอยู่จริง ๆ
- **Perceived:** คุณคิดว่าอะไรทำให้ {other} รู้สึกว่าคุณฟังอยู่จริง ๆ
- **maxSelect:** 2
- **Options:**
  - `q05_eye_contact` สบตา วางโทรศัพท์
  - `q05_repeat_back` ทวนสิ่งที่เราพูดให้ฟัง
  - `q05_ask_more` ถามต่อด้วยความอยากรู้
  - `q05_no_interrupt` ไม่พูดแทรกจนกว่าเราจะพูดจบ
  - `q05_remember_later` จำได้และพูดถึงอีกในภายหลัง
- **Interpretation:** สิ่งที่ "ฟังแล้ว" ของแต่ละคนต่างกัน คนหนึ่งอาจตั้งใจฟังแต่แสดงออกไม่ตรงกับที่อีกคนรับรู้
- **Reflection Prompt:** "ตอนไหนที่เรารู้สึกว่าอีกคนฟังเราจริง ๆ?"

#### Q06
- **Self:** ถ้าต้องการพูดเรื่องที่อาจทำให้อีกคนไม่สบายใจ คุณมักเริ่มอย่างไร
- **Perceived:** คุณคิดว่า {other} มักเริ่มพูดเรื่องที่อาจทำให้คุณไม่สบายใจอย่างไร
- **maxSelect:** 1
- **Options:**
  - `q06_direct` พูดตรง ๆ เลย
  - `q06_soften` เกริ่นนำก่อน ค่อย ๆ เข้าเรื่อง
  - `q06_wait_moment` รอจังหวะที่บรรยากาศดี
  - `q06_hint` พูดอ้อม ๆ หวังว่าอีกคนจะเข้าใจ
  - `q06_avoid` มักไม่พูดเลย
- **Interpretation:** `hint` และ `avoid` อาจทำให้อีกฝ่ายไม่รู้ว่ามีเรื่อง — เป็นจุดที่ควรตกลง "สัญญาณ" ร่วมกัน ไม่ใช่ข้อบกพร่อง
- **Reflection Prompt:** "ถ้ามีเรื่องไม่สบายใจ อยากให้อีกคนบอกเราแบบไหน?"

### D03 — ปฏิกิริยาต่อความขัดแย้ง

#### Q07 ⭐quick
- **Self:** เมื่อเริ่มมีความขัดแย้ง ปฏิกิริยาแรกของคุณมักเป็นแบบไหน
- **Perceived:** คุณคิดว่าเมื่อเริ่มขัดแย้งกัน ปฏิกิริยาแรกของ {other} มักเป็นแบบไหน
- **maxSelect:** 2
- **Options:**
  - `q07_engage` อยากคุยให้จบเดี๋ยวนี้
  - `q07_pause` ขอพักก่อน
  - `q07_defend` อธิบายเหตุผลของตัวเอง
  - `q07_quiet` เงียบลง
  - `q07_appease` ยอมไปก่อนเพื่อให้สงบ
- **Interpretation:** คู่ที่คนหนึ่ง `engage` อีกคน `pause` เป็นรูปแบบที่พบบ่อย ทั้งสองแบบมีเหตุผล การรู้ว่าอีกฝ่ายต้องการอะไรช่วยลดการไล่-หนี
- **Reflection Prompt:** "ตอนเริ่มทะเลาะ อยากให้อีกคนทำอะไรเป็นอย่างแรก?"

#### Q08
- **Self:** ระหว่างทะเลาะ อะไรทำให้คุณรู้สึกแย่ลงที่สุด
- **Perceived:** คุณคิดว่าระหว่างทะเลาะ อะไรทำให้ {other} รู้สึกแย่ลงที่สุด
- **maxSelect:** 2
- **Options:**
  - `q08_raised_voice` เสียงที่ดังขึ้น
  - `q08_silence` การถูกเงียบใส่
  - `q08_old_issues` การยกเรื่องเก่ามาพูด
  - `q08_dismissed` การถูกบอกว่าคิดมากไป
  - `q08_leaving` การที่อีกคนเดินหนีโดยไม่บอกว่าจะกลับมาคุย
- **Interpretation:** ข้อนี้ระบุ "จุดเจ็บ" ไม่ใช่การกล่าวหาว่าอีกฝ่ายทำ ห้ามแสดงผลในรูป "{other} ทำสิ่งนี้"
- **Reflection Prompt:** "มีอะไรที่เราสองคนตกลงกันได้ว่าจะไม่ทำตอนทะเลาะ?"

#### Q09
- **Self:** หลังจากทะเลาะ คุณมักใช้เวลานานแค่ไหนกว่าจะพร้อมคุยดี ๆ
- **Perceived:** คุณคิดว่า {other} ใช้เวลานานแค่ไหนกว่าจะพร้อมคุยดี ๆ หลังทะเลาะ
- **maxSelect:** 1
- **Options:**
  - `q09_minutes` ไม่กี่นาที
  - `q09_hour` ประมาณหนึ่งชั่วโมง
  - `q09_sleep_on_it` ขอนอนก่อนสักคืน
  - `q09_days` อาจหลายวัน
- **Interpretation:** ความต่างของเวลาฟื้นตัวไม่ได้สะท้อนว่าใครใส่ใจมากกว่า แค่ระบบประสาทและนิสัยต่างกัน
- **Reflection Prompt:** "ระหว่างที่อีกคนยังไม่พร้อม อยากให้เราทำอะไร?"

### D04 — ความต้องการความมั่นใจ

#### Q10 ⭐quick
- **Self:** อะไรทำให้คุณมั่นใจว่าความสัมพันธ์ยังโอเคดี
- **Perceived:** คุณคิดว่าอะไรทำให้ {other} มั่นใจว่าความสัมพันธ์ยังโอเคดี
- **maxSelect:** 2
- **Options:**
  - `q10_words` ได้ยินคำพูดตรง ๆ เช่น "รักนะ"
  - `q10_checkin` การทักมาถามระหว่างวัน
  - `q10_time` การใช้เวลาด้วยกันสม่ำเสมอ
  - `q10_actions` การกระทำเล็ก ๆ ที่แสดงว่าคิดถึง
  - `q10_no_need` ไม่ต้องการสัญญาณมาก รู้สึกมั่นใจอยู่แล้ว
- **Interpretation:** ความต้องการความมั่นใจมากหรือน้อยเป็นเรื่องปกติทั้งคู่ ห้ามตีความว่า "ขี้หึง" หรือ "เย็นชา"
- **Reflection Prompt:** "สัญญาณเล็ก ๆ อะไรที่ทำให้เรารู้สึกอุ่นใจที่สุด?"

#### Q11
- **Self:** เวลาอีกคนตอบข้อความช้ากว่าปกติ คุณมักรู้สึกอย่างไร
- **Perceived:** คุณคิดว่าเวลาคุณตอบข้อความช้า {other} มักรู้สึกอย่างไร
- **maxSelect:** 1
- **Options:**
  - `q11_fine` ไม่คิดอะไร คงยุ่งอยู่
  - `q11_curious` สงสัยนิดหน่อย
  - `q11_worried` เริ่มกังวลว่ามีอะไรหรือเปล่า
  - `q11_overthink` คิดไปไกล แต่ไม่ได้พูด
- **Interpretation:** เชื่อมกับเหตุการณ์ใน Ch1–Ch2 ใช้ทำความเข้าใจว่าความเงียบมีความหมายต่างกันต่อแต่ละคน
- **Reflection Prompt:** "ถ้าต้องหายไปนาน ๆ อยากให้อีกคนบอกเราแบบไหน?"

#### Q12
- **Self:** เมื่อรู้สึกไม่มั่นใจในความสัมพันธ์ คุณมักทำอย่างไร
- **Perceived:** คุณคิดว่าเมื่อ {other} รู้สึกไม่มั่นใจ มักทำอย่างไร
- **maxSelect:** 2
- **Options:**
  - `q12_ask_direct` ถามตรง ๆ

### D11 — ขอบเขตส่วนตัว

#### Q31 ⭐quick
- **Self:** เรื่องไหนที่สำคัญมากสำหรับคุณในการรู้สึกว่าถูกเคารพ
- **Perceived:** คุณคิดว่าเรื่องไหนที่สำคัญมากสำหรับ {other} ในการรู้สึกว่าถูกเคารพ
- **maxSelect:** 3
- **Options:**

  - `q31_own_friends` เวลากับเพื่อนหรือครอบครัวของตัวเอง
  - `q31_decisions` การตัดสินใจเรื่องของตัวเอง
  - `q31_tone` น้ำเสียงเวลาคุยกัน แม้ตอนไม่พอใจ
  - `q31_not_shared` ไม่เล่าเรื่องส่วนตัวของเราให้คนอื่นฟัง
  - `q31_body` การถามก่อนสัมผัสในบางสถานการณ์
- **Interpretation:** ขอบเขตไม่ใช่การปิดกั้น การรู้ขอบเขตช่วยให้ทั้งคู่รู้สึกปลอดภัย
- **Reflection Prompt:** "มีขอบเขตไหนที่เราอยากให้อีกคนรู้ แต่ยังไม่เคยบอกตรง ๆ?"

#### Q32
- **Self:** เมื่อมีคนข้ามขอบเขตของคุณ คุณมักทำอย่างไร
- **Perceived:** คุณคิดว่าเมื่อคุณข้ามขอบเขตของ {other} เขามักทำอย่างไร
- **maxSelect:** 1
- **Options:**

  - `q32_say_later` บอกภายหลังเมื่อใจเย็นแล้ว
  - `q32_hint` แสดงออกทางอ้อม
  - `q32_keep_inside` เก็บไว้ในใจ
- **Interpretation:** `keep_inside` อาจทำให้อีกฝ่ายไม่รู้ว่าข้ามขอบเขตไปแล้ว — ใช้ชวนคุยเรื่องการสื่อสาร ไม่ใช่โทษ
- **Reflection Prompt:** "ถ้าเราทำอะไรที่ทำให้อีกคนอึดอัด อยากให้เขาบอกเราแบบไหน?"

#### Q33
- **Self:** ตอนทะเลาะกัน มีข้อตกลงไหนที่คุณอยากให้เราสองคนมีร่วมกัน
- **Perceived:** คุณคิดว่าข้อตกลงไหนที่ {other} อยากให้มีตอนทะเลาะกัน
- **maxSelect:** 5 (เลือกได้ทุกข้อ — audit H-8)
- **Options:**
  - `q33_no_insults` ไม่ใช้คำด่าหรือคำดูถูก
  - `q33_no_threats_leave` ไม่ขู่ว่าจะเลิก
  - `q33_not_public` ไม่ทะเลาะต่อหน้าคนอื่น
  - `q33_no_mocking` ไม่ล้อเลียนความรู้สึกของกัน
  - `q33_say_when_back` ถ้าต้องเงียบ ให้บอกว่าจะกลับมาคุยเมื่อไร
- **หมายเหตุ Safety:** ใต้คำถามแสดงข้อความคงที่ *"การทำร้ายร่างกาย การทุบขว้างของ หรือการข่มขู่ ไม่ใช่เรื่องของความชอบ — ไม่ควรเกิดขึ้นในความสัมพันธ์ ถ้าเกิดขึ้น คุณขอความช่วยเหลือได้"* + ลิงก์ S11 · ไม่นำพฤติกรรมเหล่านี้มาเป็นตัวเลือก
- **Interpretation:** ข้อนี้ช่วยตั้ง "ข้อตกลงร่วม" ไม่ใช่รายการกล่าวหา หากข้อความอิสระบ่งชี้ถึงความรุนแรงที่เกิดขึ้นจริง ให้แสดงข้อมูลแหล่งช่วยเหลือ ([08](08-privacy-and-safety.md) §9)
- **Reflection Prompt:** "มีอะไรที่เราสองคนอยากตกลงกันว่าจะไม่ทำ แม้ตอนโกรธที่สุด?"
