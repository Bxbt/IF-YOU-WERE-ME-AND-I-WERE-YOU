## 1. Design Foundations

### 1.1 Color Tokens

| Token | Hex | ใช้กับ |
|---|---|---|
| `--c-navy` | #171C2F | พื้นหลังหลัก, ท้องฟ้ากลางคืน |
| `--c-indigo` | #292B45 | พื้นผิว Panel, กล่อง Dialogue |
| `--c-lavender` | #A49BCB | ข้อความรอง, เส้นขอบ, MONO |
| `--c-cream` | #F3EBDD | ข้อความหลัก |
| `--c-pink` | #D9A3A7 | Accent ผู้เล่น A, ปุ่มยืนยันเชิงอารมณ์ |
| `--c-orange` | #E9B77B | Accent แสงอุ่น, Focus ring, ปุ่มหลัก |
| `--c-blue` | #8EACC8 | Accent ผู้เล่น B, ข้อมูล |
| `--c-danger` | #E08A7E | การลบข้อมูลเท่านั้น (เพิ่มจาก palette, โทนเดียวกัน) |

- ธีมเดียว (กลางคืน) — ไม่มี Light mode ใน MVP
- **สีของผู้เล่น A/B ใช้เพื่อแยกตัวตนเท่านั้น** ห้ามใช้สีเขียว/แดงเพื่อสื่อ "ตรงกัน/ไม่ตรงกัน"
- ทุกคู่สีข้อความ/พื้นหลังต้องผ่าน WCAG 2.2 AA (≥ 4.5:1 ข้อความปกติ, ≥ 3:1 ข้อความใหญ่และ UI) — ตรวจด้วยเครื่องมือตอนพัฒนา (TC-A11Y-02)

### 1.2 Typography (A-08)

| บทบาท | ฟอนต์ | ขนาด (mobile / desktop) |
|---|---|---|
| ชื่อเกม / Title card ภาษาอังกฤษ | Silkscreen (pixel) | 28 / 48px |
| หัวข้อไทย | IBM Plex Sans Thai SemiBold | 20 / 28px |
| เนื้อหา, Dialogue | IBM Plex Sans Thai Regular | 17 / 19px, line-height 1.7 |
| ตัวเลือก | IBM Plex Sans Thai Medium | 16 / 18px |
| ข้อความเล็ก/ป้าย | IBM Plex Sans Thai | 13 / 14px (ห้ามต่ำกว่า 13px) |

- ผู้เล่นปรับขนาดตัวอักษรได้ 3 ระดับ (100% / 115% / 130%) ใน S10
- ห้ามใช้ pixel font กับข้อความภาษาไทย (อ่านยาก)

### 1.3 Spacing, Shape, Motion

| Token | ค่า |
|---|---|
| Spacing scale | 4, 8, 12, 16, 24, 32, 48px |
| Side gutter | 16px (mobile), 24px (tablet), auto-center max 1120px (desktop) |
| Panel radius | 16px · ปุ่ม 12px · มีขอบ pixel 2px (`--c-lavender` 40% opacity) |
| Shadow | `0 8px 24px rgba(0,0,0,.35)` |
| Touch target | ≥ 44×44px |
| Transition หน้าจอ | fade + slide 8px, 240ms, ease-out (Framer Motion) |
| Dialogue typing | 30 ตัวอักษร/วินาที (ปรับ: ช้า 20 / ปกติ 30 / เร็ว 60 / ทันที) |
| Reduced motion | `prefers-reduced-motion` หรือสวิตช์ใน S10 → ปิด parallax, particles, screen shake; transition เหลือ fade 120ms; typing = ทันที |

### 1.4 Breakpoints

| ชื่อ | ความกว้าง | Layout หลักของ S6 |
|---|---|---|
| `sm` | < 640px | Scene ด้านบนเต็มความกว้าง (16:9) · Dialogue + ตัวเลือกด้านล่าง เลื่อนได้ |
| `md` | 640–1023px | Scene เต็มความกว้าง · Dialogue ซ้อนทับด้านล่างของ Scene |
| `lg` | ≥ 1024px | Scene กลางจอ สูงสุด 1280×720 · Dialogue ซ้อนทับ · ตัวเลือกด้านขวาของกล่อง Dialogue ถ้ามีพื้นที่ |

- Landscape บนมือถือ (สูง < 480px): Scene ด้านซ้าย 60%, Dialogue ด้านขวา 40%
- ไม่มี Horizontal scroll ทุกขนาด

### 1.5 Pixel Scene Canvas

- ความละเอียดตรรกะ **320×180** (16:9) ทุก Background และ Sprite วาดบนกริดนี้
- Scale เป็นจำนวนเต็มที่ใหญ่ที่สุดที่พอดี (`floor`) ช่องว่างที่เหลือเติม `--c-navy` (letterbox) · ถ้าจอแคบกว่า 320px ใช้ scale ไม่เต็มจำนวน + `image-rendering: pixelated`
- ข้อความทั้งหมดเป็น HTML ซ้อนทับ ไม่วาดลง Canvas

### S1a — Safety Intro

- การ์ด 3 ข้อ (เลื่อนแนวนอนบน sm, เรียงแถวบน lg): "ไม่มีคะแนน ไม่มีใครผิด" · "ข้ามหรือหยุดได้ทุกเมื่อ" · "คำตอบเป็นของคุณ คุณเลือกเองว่าจะให้ใครเห็น"
- ลิงก์ "อ่านเพิ่มเติม" → S11
- ปุ่ม "เข้าใจแล้ว เริ่มเลย" → S2
- แสดงครั้งแรกของแต่ละ Journey · ข้ามได้ด้วยปุ่มเดียวกัน

### S1b — Journey List (Phase 2)

- รายการการ์ด: ชื่อผู้เล่น, โหมด, บทล่าสุด, วันที่เล่นล่าสุด (ไม่แสดงเนื้อหาคำตอบ)
- แต่ละการ์ด: เล่นต่อ · ส่งออก · ลบ (ConfirmDialog)
- สูงสุด 5 Journey · ถ้าเต็ม ปุ่มเริ่มใหม่ใน S1 แสดง Dialog ให้ลบหรือส่งออกก่อน
- Empty → redirect S1

| Solo เมื่อมีตัวตนอยู่แล้ว | ถ้ามีผู้เล่นจริงอยู่แล้ว ขั้นแรกคือ "คุณคือใครในการเดินทางนี้": การ์ดตัวตนเดิม (ภาพ + ชื่อ) ให้เลือก **(ค่าเริ่มต้น = ตัวตนที่ใช้ล่าสุด)** หรือ "สร้างตัวตนใหม่" — ใช้ตัวตนเดิมแล้วข้ามไปสร้างคู่เลย เพราะคำตอบ Q01–Q36 เป็นของผู้เล่น ใช้ข้าม Journey ได้ ([04](04-personality-system.md) §2.1, [05](05-game-flow.md) §3.2) · ห้ามสร้างตัวตนซ้ำโดยผู้เล่นไม่ได้เลือก |

### เต็มจอ (2026-11-23 ตามเจ้าของ)

- เปิดจากไอคอนหน้าจอโฮมอยู่แล้ว (standalone) → ไม่แสดงปุ่ม
- `public/manifest.webmanifest`: `display: "fullscreen"` (Android ซ่อนแถบทั้งหมด; iOS ใช้แบบ standalone) · ไอคอน 192/512 · สี navy · meta `apple-mobile-web-app-capable` + status bar สีดำ (ไม่ทับเนื้อหา)

## 4. Accessibility Requirements

| ID | ข้อกำหนด |
|---|---|
| AX-1 | ทุกการกระทำทำได้ด้วยคีย์บอร์ด (Tab, Shift+Tab, Enter, Space, Esc, ตัวเลข) ลำดับ Tab เป็นธรรมชาติ |
| AX-2 | Focus ring มองเห็นชัด (`--c-orange` 3px + offset 2px) ทุกองค์ประกอบ |
| AX-3 | Dialogue ใหม่ประกาศผ่าน `aria-live="polite"` (ข้อความเต็ม ไม่ใช่ทีละตัว) |
| AX-4 | ทุกฉากมี `aria-label` คำอธิบายภาพ (เช่น "ร้านสะดวกซื้อหน้าตึก ฝนตกหนักนอกกระจก") ใน content |
| AX-5 | ไม่สื่อความหมายด้วยสีอย่างเดียว — ใช้ไอคอน + ข้อความร่วม |
| AX-6 | Modal มี focus trap และคืน focus เมื่อปิด |
| AX-7 | ไม่มีเนื้อหากระพริบเกิน 3 ครั้ง/วินาที (ฟ้าแลบในร้าน/ไฟกระพริบ ≤ 2 ครั้ง/วินาที และปิดได้ด้วย reduced motion) |
| AX-8 | Zoom 200% ไม่ตัดข้อความ ไม่เกิด horizontal scroll · ไม่ปิดการซูมของผู้ใช้ (ไม่ใช้ `user-scalable=no`/`maximum-scale`) |
| AX-8a | ช่องพิมพ์ (input/textarea/select) บนจอสัมผัสใช้ตัวอักษรอย่างน้อย 16px เพื่อไม่ให้ iOS ซูมเข้าเองเมื่อแตะ |
| AX-9 | ภาษาเอกสาร `lang="th"` · ข้อความอังกฤษครอบ `lang="en"` |
| AX-10 | ตัวเลือกใน ChoiceList เป็น `<button>` ใน `role="group"` พร้อม `aria-pressed` สำหรับ multi-select |
