# 02 — Story Script

> เจ้าของข้อมูล: บท ฉาก Dialogue ตัวเลือก Flags และ Reflection ทั้งหมด
> **เนื้อเรื่องทั้งหมดเป็นเรื่องสมมติ** ไม่ได้อิงเหตุการณ์จริงของผู้ใด (A-02) ผู้เล่นปรับรายละเอียดบางส่วนได้ใน Scenario Setup

## 0. Conventions

### 0.1 Tokens

| Token | แทนที่ด้วย |
|---|---|
| `{A}` / `{B}` | ชื่อเล่นของ Player A / Player B (หรือ Imagined Partner) |
| `{in}` | ชื่อของตัวละครที่ได้บทบาท `insider` (ติดลิฟต์) |
| `{out}` | ชื่อของตัวละครที่ได้บทบาท `waiter` (รอข้างนอก) |
| `{in.end}` / `{out.end}` | คำลงท้ายที่ผู้เล่นคนนั้นเลือก เช่น "ครับ" "ค่ะ" "นะ" หรือว่าง (A-04) |
| `{me}` / `{other}` | ชื่อของผู้เล่นที่กำลังตอบ / ชื่อของอีกฝ่าย (ใช้ใน Reflection และ Mirror) |
| `{you}` | คำที่ผู้พูดใช้เรียกคู่ ตาม `addressStyle` ของผู้พูด: "เธอ" / "ตัวเอง" / ชื่อของคู่ ([07](07-data-architecture.md) §3) |

**สรรพนาม:** ผู้บรรยายใช้ชื่อแทนสรรพนามบุรุษที่ 3 เสมอ (ไม่ใช้ "เขา/เธอ" ระบุเพศ) · ในบทพูดระหว่างคู่ เอกสารนี้เขียน "เธอ" เพื่อให้อ่านง่าย แต่ในไฟล์ Content ทุกคำ "เธอ" ที่หมายถึงคู่ต้องเขียนเป็น `{you}` (A-22)

### 0.2 ประเภทบรรทัด

| Type | การแสดงผล |
|---|---|
| `NARR` | ผู้บรรยาย กล่องกลางจอ ตัวอักษรปกติ |
| `DLG` | บทพูด มีชื่อผู้พูด + Portrait สีหน้า |
| `MONO` | ความคิดในใจ ตัวเอียง สีจาง ไอคอนก้อนเมฆ |
| `SYS` | ข้อความระบบ เช่น หน้าจอโทรศัพท์ ป้ายลิฟต์ |
| `CHOICE` | ตัวเลือก ระบุ `owner` (บทบาทที่เป็นคนเลือก) |
| `ENV` | คำสั่งเปลี่ยนบรรยากาศ (ไม่แสดงเป็นข้อความ) |

### 0.3 Scenario Setup (ก่อน Ch1)

หน้าจอสั้น ๆ ก่อนเริ่ม Ch1 (เล่นครั้งแรก หรือเมื่อเลือก Ch ใดโดยยังไม่เคยตั้งค่า)

```
SYS  เรื่องต่อไปนี้เป็นเรื่องสมมติ คุณปรับรายละเอียดบางอย่างได้
Q    ในเรื่องนี้ ใครจะเป็นคนที่ติดอยู่ในลิฟต์?
     Solo:     [ ฉันเอง ]  [ {other} ]  [ ให้เกมสุ่ม ]
     Together: [ {A} ]  [ {B} ]  [ ให้เกมสุ่ม ]
Q    ก่อนหน้านี้ เคยมีการเตือนกันเรื่องลิฟต์ตัวนี้ไหม?
     [ มี (ค่าเริ่มต้น) ]  [ ไม่มี ]
SYS  เปลี่ยนการตั้งค่านี้ได้ทุกเมื่อจากเมนูหยุดเกม (จะเริ่มบทใหม่)
```

ผลลัพธ์: `scenario.insiderPlayerId`, `scenario.priorWarning` (ดู [07](07-data-architecture.md) §5)

### 0.4 Content Checklist (ทุกบรรทัดต้องผ่าน)

- [ ] ไม่มีตัวละครใดเป็นผู้ร้าย ทั้งสองบทบาทได้ MONO อธิบายเหตุผลของตัวเอง
- [ ] ไม่มีตัวเลือกที่ถูกเขียนให้ดู "ถูกต้อง" กว่าตัวอื่น (ความยาวและน้ำเสียงใกล้เคียงกัน)
- [ ] ความโกรธ/หงุดหงิด ได้รับการยอมรับว่ามีที่มา แต่เกมไม่สื่อว่าความกังวลทำให้คำพูดที่ทำร้ายกลายเป็นเรื่องปกติ
- [ ] ทุกฉากที่มีการกอด มีตัวเลือกที่ไม่กอด และตัวเลือก "ขอถามก่อน"
- [ ] ทุกฉากที่มีการขอโทษ มีตัวเลือกที่ไม่ขอโทษ
- [ ] ไม่มีศัพท์วินิจฉัย (เช่น วิตกกังวลผิดปกติ, toxic, ขี้หึง, เอาแต่ใจ)
- [ ] การตีความใช้คำว่า "อาจ" เสมอ และผู้เล่นยืนยันเอง

### 0.5 กฎการมองเห็นตามโหมด

| ส่วน | Play Alone | Play Together (A-05) | Remote |
|---|---|---|---|
| ตัวเลือกเนื้อเรื่อง Ch1–Ch3 | ผู้เล่นเลือกทุกบทบาท | เจ้าของบทบาทเลือก อีกคนดูอยู่ด้วย | **เล่นแบบ Solo บนเครื่องตัวเอง**: เลือกทุกบทบาท บทบาทของคู่มี Imagined Banner · ไม่ส่งตัวเลือกข้ามเครื่อง (audit H-1 — กันการรออีกฝ่ายจนติดค้าง) |
| Interpretation Check (Ch3) | ส่วนตัว | ส่วนตัว + Handoff | ส่วนตัว (ไม่ส่งขึ้น Server) |
| Reflection ท้ายบท | ส่วนตัว | ส่วนตัว + Handoff | ส่วนตัว |
| Mirror (Ch3 S05, Ch4) | ส่วนตัว | ส่วนตัว → Reveal เมื่อยินยอมทั้งคู่ | ส่วนตัว → Reveal เมื่อยินยอมทั้งคู่ (สิ่งเดียวที่แชร์ข้ามเครื่อง ร่วมกับ Ch5) |
| Ch5 Statements | ส่วนตัว | ส่วนตัว → แชร์ทีละข้อ | เช่นเดียวกัน |

### 0.6 Imagined Banner (Play Alone)

เมื่อผู้เล่นควบคุมบทบาทของคู่ (ไม่ใช่ตัวเอง) แสดงแถบด้านบนตลอดฉาก:

> 💭 นี่คือสิ่งที่คุณจินตนาการว่า {other} อาจรู้สึก — ไม่ใช่สิ่งที่ {other} บอก

(ไอคอนใช้ Lucide `Cloud` ไม่ใช้ emoji ใน UI จริง)

### 0.7 Observed Tags

ตัวเลือกบางตัวมี `tag` = `Dxx:signal` เพื่อป้อน Observed Pattern ใน Phase 2 ([04](04-personality-system.md) §5) — MVP ใส่ tag ไว้ใน Content แต่ไม่เก็บสัญญาณ
- เลือกในบทบาทของตัวเอง → สัญญาณของผู้เล่นนั้น
- เลือกในบทบาทของอีกฝ่าย → ไม่เก็บ


**ถ้า `priorWarning = false`:**

### Possible Emotional Interpretations — Ch1

แสดงเป็น "การ์ดความรู้สึก" หลังฉากจบ ผู้เล่นแตะการ์ดที่คิดว่า "อาจ" เป็นไปได้ (ไม่บังคับ บันทึกเป็น Reflection)

| บทบาท | การ์ด |
|---|---|
| insider | ตกใจ · กลัว · รู้สึกช่วยตัวเองไม่ได้ · อึดอัด · รำคาญ · อาย · ยังสงบอยู่ |
| waiter | สงสัย · กังวล · คิดไปถึงเรื่องแย่ที่สุด · หงุดหงิด · รู้สึกช่วยอะไรไม่ได้ · ยังไม่แน่ใจว่าเกิดอะไรขึ้น |

ข้อความใต้การ์ด: *"ไม่จำเป็นต้องเลือก และไม่มีความรู้สึกไหนที่ผิด"*

**Safety Notes (แสดงตามเงื่อนไข, เป็นกล่องข้อความเล็กที่แตะปิดได้):**
- หลัง `out_first_words=blame`: *"ความกังวลเป็นสิ่งที่เข้าใจได้ — แต่ไม่ได้แปลว่าคำพูดที่ทำให้อีกคนเจ็บเป็นเรื่องที่ไม่เป็นไร ทั้งสองอย่างจริงได้พร้อมกัน"*
- หลัง `in_resp=apologize`: *"การขอโทษเป็นทางเลือก ไม่ใช่สิ่งที่ต้องทำเพื่อให้เรื่องจบ"*
- หลัง `in_resp=boundary`: *"การขอเวลาไม่ใช่การปฏิเสธ"*

### Possible Emotional Interpretations — `ch3_s04` "เบื้องหลังคำพูด" (Interpretation Check)

หัวข้อ: **"คำพูดนี้อาจมีความรู้สึกเหล่านี้อยู่เบื้องหลัง — หรืออาจไม่มีเลยก็ได้"**
แต่ละรายการให้เลือก: `ใช่` / `ไม่ใช่` / `ไม่แน่ใจ` และมีข้อ "ไม่มีข้อไหนตรงเลย" + ช่องข้อความอิสระ

| คำพูด | ความรู้สึกที่อาจอยู่เบื้องหลัง |
|---|---|
| out: relief | โล่งใจ · ยังตกใจอยู่ · ไม่รู้จะพูดอะไรดี |
| out: fear | กลัว · อยากให้รู้ว่าสำคัญแค่ไหน · ต้องการการปลอบเหมือนกัน |
| out: blame | กลัวจะเสียไป · รู้สึกช่วยอะไรไม่ได้ · น้อยใจที่คำเตือนไม่ถูกรับฟัง (เฉพาะ priorWarning) · เหนื่อยจากความกังวล · โกรธจริง ๆ |
| out: ask_hug | อยากสัมผัสเพื่อยืนยันว่าปลอดภัย · ต้องการความใกล้ชิด · อยากปลอบ |
| out: silent | ไม่รู้จะเริ่มอย่างไร · กลัวพูดผิด · อยากให้พื้นที่ · กำลังข่มอารมณ์ |
| in: apologize | รู้สึกผิด · อยากให้บรรยากาศดีขึ้น · ไม่อยากทะเลาะ · เหนื่อยเกินกว่าจะอธิบาย |
| in: boundary | ต้องการเวลา · ยังกลัวอยู่ · รู้สึกไม่ถูกเข้าใจ |
| in: share_fear | อยากได้รับการปลอบ · อยากให้รู้ว่าตัวเองก็เจอเรื่องหนัก |
| in: withdraw | ท่วมท้น · ต้องการพื้นที่ · เสียใจ |
| in: hurt | อยากให้รู้ว่าคำพูดมีผล · ยังกลัวอยู่ · อยากได้การปลอบก่อนคำถาม |
| in: hug_yes / hug_later | ต้องการความอบอุ่น / ต้องการเวลาก่อนถูกสัมผัส |

**ใครตอบอะไร:**
- เจ้าของคำพูด → ตอบว่า "ตัวเองรู้สึกแบบนั้นจริงไหม" (`layer=self`)
- อีกฝ่าย → ตอบว่า "คิดว่าเจ้าของคำพูดรู้สึกแบบนั้นไหม" (`layer=perceived`)
- Solo: ผู้เล่นตอบในฐานะตัวเองสำหรับบทบาทของตัวเอง และตอบแบบ "จินตนาการ" สำหรับบทบาทของคู่

### Perspective Mirror — `ch3_s05` "What You See vs. What I Feel"

|---|---|---|---|
| `w3_1` | ตอนเจอหน้ากัน คุณ (ในบทบาท {role}) รู้สึกอะไรมากที่สุด | คุณคิดว่า {other} รู้สึกอะไรมากที่สุด | ชุดอารมณ์ `EMO_SET` เลือกสูงสุด 3 + ข้อความอิสระ + Meta |

`EMO_SET`: กลัว · โล่งใจ · โกรธ · น้อยใจ · รู้สึกผิด · เหนื่อย · ท่วมท้น · อาย · รัก/ห่วง · ไม่รู้สึกอะไรชัดเจน

`w3_1`, `w3_2` มี `context: role` — ใช้เฉพาะในฉากนี้ ไม่นับเป็นข้อมูลบุคลิกภาพ และไม่ใช้ใน Comparison/Report ([04](04-personality-system.md) §2.1)

Reveal ตามกฎ [04](04-personality-system.md) §6 แสดงคู่การ์ด "สิ่งที่ {A} รู้สึก" ↔ "สิ่งที่ {B} คิดว่า {A} รู้สึก" และในทางกลับกัน

ข้อความหลัง Reveal (Template ตามหมวด):
- เหมือนกัน: *"สิ่งที่ {viewer} เห็น ตรงกับสิ่งที่ {owner} รู้สึก — ลองบอกกันดูไหมว่ารู้ได้อย่างไร"*
- ต่างกัน: *"สิ่งที่มองเห็นจากข้างนอก อาจไม่ใช่ทั้งหมดที่อยู่ข้างใน — นี่คือสิ่งที่น่าคุยกันต่อ"*
- มีไม่แน่ใจ/ข้าม: *"บางเรื่องเรายังไม่รู้ และนั่นก็โอเค เก็บไว้เป็นคำถามครั้งหน้า"*
